## Sobre
> Este é um projeto do módulo "Rotas e HTTP" da trilha de NodeJS da Rocketseat. Trata-se de uma API construída com Fastify, Knex e Zod para validação. Inclui testes automatizados com Vitest.

## Como Usar
Se você quiser baixar apenas esta pasta deste repositório, siga os passos abaixo:

1. Copie a URL da barra de endereço do seu navegador;
2. Substitua 'tree/main' ou 'tree/master' por 'trunk';

Exemplo: 
> https://github.com/User/somerepo/tree/main/folderyouwant
 
> https://github.com/User/somerepo/trunk/folderyouwant 

3. Vá para a Linha de Comando e baixe a pasta com SVN:

```sh
    svn checkout https://github.com/User/somerepo/trunk/folderyouwant 
```

4. Após baixar, entre na pasta, instale as dependências e rode a aplicação:
```sh
    npm install
    npm run dev
```
*(Você também pode rodar `npm test` para os testes locais)*
